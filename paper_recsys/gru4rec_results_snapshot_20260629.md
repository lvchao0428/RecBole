## 4. 当前可直接读出的结论

### 4.1 Beauty

- `TF-IDF` 相比 `ID-only` 有明显提升：
  - `MRR@10`: `1.42% -> 3.21%`
  - `HR@10`: `2.87% -> 5.87%`
  - `NDCG@10`: `1.76% -> 3.83%`
- `TF-IDF+LLM` 继续小幅抬升到 `3.27 / 5.97 / 3.90`
- `MV` 是当前 Beauty 上最优 text 配置：`3.30 / 6.17 / 3.98`
- 在 GRU4Rec backbone 上，文本特征并不是 marginal gain，而是大幅抬升整体排序质量；`MV` 在 Beauty 上相对 `TF-IDF` 和 `TF-IDF+LLM` 都还有稳定小增益。

### 4.2 Toys

- `TF-IDF` 相比 `ID-only` 同样稳定提升：
  - `MRR@10`: `1.59% -> 3.77%`
  - `HR@10`: `3.07% -> 6.76%`
  - `NDCG@10`: `1.94% -> 4.47%`
- `TF-IDF+LLM` 提升到 `3.82 / 6.84 / 4.52`
- `MV` 在 Toys 上把 `HR@10 / NDCG@10` 再抬到 `7.09 / 4.58`
- Toys 上的提升幅度比 Beauty 还更整齐，说明 GRU4Rec 下文本增强并不只是单一数据集偶然；而且 `MV` 在 Toys 上的优势比 Beauty 更明显。

### 4.3 当前最稳妥的写法

- 现阶段可以把 GRU4Rec 写成一个**第二 backbone sanity check**
- 但更适合先强调：
  - `ID-only -> TF-IDF` 的增益是稳定且幅度大的
  - `TF-IDF -> TF-IDF+LLM -> MV` 呈现出继续抬升或至少不退化的趋势
  - `32/32` 训练已经完成
- 当前已经能写成完整四配置表
