# 更多文本视图有用吗？——面向序列推荐的泄漏感知文本表征评估

## 摘要

文本特征被广泛用于增强序列推荐系统，但对词法特征、单视图 LLM 特征和基于提示的多视图特征之间的比较，通常在允许时间重叠的评估协议下进行。我们对 ID-only、截断拟合 TF-IDF、单视图 Qwen2.5-7B 以及四视图 LLM 表征进行泄漏感知控制研究，在三个 Amazon 数据集上使用全排序全局时间分割（GTS），以 GTS-Last 作为主协议，GTS-Random 作为鲁棒性检查，干净的留一法（LOO）作为对照。

三个发现：

**第一，评估协议改变结论。** 在所有评估设置下，文本特征一致优于 ID-only（warm targets），但 TF-IDF、单视图 LLM 和多视图 LLM 的相对排序在 Last、Random 和 LOO 之间发生变化——即使 Last 和 Random 评估的是同一组训练好的模型权重。

**第二，没有文本变体在不同时间窗口下稳健地占优。** 时间偏移降低了绝对性能，但保持了文本变体之间的近平局。

**第三，额外的提示视图因高度冗余而提供有限的边际价值：** 视图间 CKA 达到 0.82–0.94，拼接表征仅使用其名义有效秩的 53–55%，留一视图消融对下游几乎无影响。相比之下，TF-IDF 与 LLM 视图在几何上截然不同（CKA ≈ 0.19），表明存在一个词法–语义互补轴，而多提示堆叠并未利用这一轴。

这些结果表明，在将性能提升归因于日益复杂的 LLM 文本管线之前，应先诊断评估协议和表征冗余性。

## 1 引言

序列推荐从历史交互中预测用户的下一个物品。物品文本（标题、描述、LLM 生成的语义）是丰富 ID 嵌入和实现跨域迁移的标准方式。一个自然的工作假设是"更丰富的文本总是更好"：LLM 嵌入应该优于词袋模型，多个提示视图应该优于单视图。

**这一假设被广泛持有。** 近期工作常规性地报告 LLM 生成的物品描述优于 TF-IDF 或 Word2Vec 特征，多视图提示策略越来越多地被采用以捕捉互补的物品维度（如功能、受众、风格）。构建生产推荐系统的从业者面临具体决策：是否应投资于 LLM 推理和多提示管线来获取文本特征，还是轻量级词袋基线已经足够？答案关键取决于比较是如何评估的——这一考量在文本增强推荐论文中很少被审视。

**这一假设建立在脆弱的评估基础上。** 大多数文本增强序列推荐系统使用留一法（LOO）分割来验证，如 Ji 等人和 Sun 等人所示，这允许训练和测试之间的时间重叠，产生更高的绝对指标并可能扭曲模型比较。在部署场景中，推荐系统必须预测用户**将来**会交互的物品，而不是重建一个随机持出的历史交互。全局时间分割（GTS）更好地模拟了这一部署约束，但引入了额外的设计选择：**目标选择模式**（Last、Random、Successive 或 All）本身改变了有效任务难度，并可能改变模型排名。

此外，文本特征需要预处理——词汇构建、IDF 加权、SVD 投影和 LLM 嵌入白化——每一步都必须尊重时间边界。如果这些统计量在完整物品集上计算（包括未来物品），所得特征携带了训练时不可用的信息，引入了与训练/测试分割本身正交的泄漏形式。因此我们在全过程中强制执行严格的**截断拟合**控制。

**研究问题：**
- **RQ1 协议效应：** 干净 LOO、GTS-Last 和 GTS-Random 是否改变了 TF-IDF、单视图 LLM 和多视图的绝对增益和相对排名？
- **RQ2 时间鲁棒性：** Main 时间窗口（80% 截断）下得出的结论，在训练窗口缩小时（Early，60% 截断）是否仍然成立？
- **RQ3 多视图冗余：** 为什么四个提示视图不能可靠地超越单 LLM 视图甚至 TF-IDF？潜在互补性在哪里？

**贡献：**
1. 在三个数据集上进行泄漏感知比较，表明评估协议改变文本表征排名。在 GTS 内，同一训练检查点在 Last 与 Random 下产生不同的赢家（**目标效应**）；从 GTS 切换到 LOO 同时改变训练数据和目标（**分割效应**）。文本一致优于 ID，但**哪种**文本最好是协议敏感的。
2. 跨窗口证据表明没有单一文本变体稳健地占优：在等 horizon Early 窗口（60% 截断）下，绝对 MRR 显著下降，但文本变体在 0.001 以内。
3. 三角验证冗余分析（CKA + 有效秩 + LOOV），从原始 3584-d Qwen 隐层状态到 64-d 白化后，共同解释了有限的多视图增益，同时识别了词法–语义不相似性（TF vs LLM，CKA ≈ 0.19）作为潜在互补轴。

## 2 相关工作

### 文本增强序列推荐
早期系统将词袋或评论文本与协同过滤融合。现代方法用预训练语言模型编码标题和描述以实现跨域迁移。UniSRec 从文本学习可迁移物品表征；VQ-Rec 量化文本嵌入；P5 将推荐转化为语言建模；TALLRec 通过指令微调对齐 LLM。我们**不**提出新架构；我们在固定骨干网络下，探究更强的文本编码器和更多视图在控制时间泄漏后是否仍然有优势。

### LLM 物品表征
越来越多的做法是将 LLM 嵌入作为即插即用的物品特征——单视图或多提示视图。然而，当所有视图由**同一**预训练编码器在**同一**物品文本上用不同指令生成时，所得表征的多样性取决于编码器的内部表征对不同指令的响应程度——一个在推荐文献中很少实证关注的问题。

### 评估协议和时间泄漏
采样指标扭曲排名；LOO 与时间分割改变绝对分数并可能改变模型选择。在 GTS 中，目标选择模式很重要：Successive 最好地近似在线预测但代价高；Last 是确定性低成本代理；Random 与 Successive 的秩相关性最高；All 引入任务不匹配且相关性最弱。

### 多视图学习与表征冗余
多视图理论认为视图必须**有用且互补**；更多视图不能保证收益。CKA 衡量跨层和架构的 Gram 矩阵几何相似性；有效秩量化表征的名义维度中有多少实际被使用。我们联合部署 CKA、有效秩和 LOOV 来诊断多提示冗余。

## 3 控制研究设置

### 时间协议
- **GTS-Last（主协议）：** RecBole TS 分割 [0.8, 0.1, 0.1]（Main）或 [0.6, 0.1, 0.1]（Early，等 horizon）。每个用户贡献其**时间上最后一个**测试交互。
- **GTS-Random（鲁棒性检查）：** 同一检查点；每个用户贡献一个**均匀随机**测试交互。平均三个目标采样种子（42, 123, 456）。
- **干净 LOO（对照）：** 留一法，仅用于量化协议差距。
- **GTS-All（附录）：** 所有后截断目标，因任务不匹配而放入附录。

### 泄漏控制
TF-IDF 词汇/IDF、SVD 投影和 LLM 中心化/白化仅在训练截断前出现的物品上拟合。评估过滤训练交互 ≥ 5 的用户。主表报告 warm-target 结果（目标 ∈ 训练目录）。

### 文本表征和模型
所有变体共享 SASRec 骨干网络（d=64，2 层，2 注意力头）：
- **ID**：仅 ID 嵌入
- **TF**：截断拟合 TF-IDF → SVD 256-d → 投影头 + InfoNCE 对齐
- **LLM**：单视图 Qwen2.5-7B 嵌入（截断中心化和白化）
- **MV**：四个提示视图（描述/功能/受众/风格）→ 每视图 64-d → 256-d 拼接
- **UniSRec**：外部基线

两阶段训练：Phase A（文本头预热），Phase B（联合 BPR + InfoNCE 微调）。

### 数据集
- **Beauty**：121 万用户，25.9 万物品，202 万交互
- **Toys**：128 万用户，33.6 万物品，225 万交互
- **Grocery**：76.8 万用户，17.2 万物品，130 万交互（同平台复制）

## 4 RQ1：协议改变排名

### 核心发现（Table 1）

| 数据集 | 协议 | ID | TF | LLM | MV | UniSRec |
|--------|------|----|----|-----|----|---------|
| Beauty | GTS-Last | .0032 | .0051 | .0059 | **.0061** | .0052 |
| Beauty | GTS-Rand | .0074 | **.0122** | .0118 | .0123 | .0096 |
| Beauty | LOO | .0175 | .0251 | **.0254** | .0253 | .0239 |
| Toys | GTS-Last | .0031 | .0040 | .0035 | **.0042** | .0041 |
| Toys | GTS-Rand | .0076 | **.0113** | .0108 | .0108 | .0086 |
| Toys | LOO | .0152 | .0247 | .0258 | **.0258** | .0196 |
| Grocery | GTS-Last | .0030 | .0046 | .0047 | **.0058** | .0106 |
| Grocery | GTS-Rand | .0044 | **.0085** | .0079 | **.0085** | .0118 |

- **GTS-Last**：MV 在所有三个数据集上领先（Beauty .0061，Toys .0042，Grocery .0058），但领先幅度小且常在一个标准差以内。
- **GTS-Random**（3 采样种子平均）：TF 在 Toys 上领先（.0113）；Beauty 上 TF ≈ MV（.0122/.0123）；Grocery 上 TF = MV（.0085）。
- **LOO**：绝对 MRR 是 GTS-Last 的 3–6 倍；排名变为 LLM ≈ MV ≥ TF。

### LOO 膨胀机制
LOO 下 3–6 倍的更高绝对值不仅仅是加性偏移——它们改变了文本方法之间的相对排序。LOO 允许时间重叠：用户的训练交互包含与测试目标同时期的物品，使模型能够"记忆"在严格时间截断下不存在的共现模式。一个合理的解释是，这种记忆不成比例地有利于捕捉细粒度语义相似性的表征（LLM 和 MV），因为重叠物品为语义特征提供了比词法特征更丰富的共现信号。

### 为什么 Last 和 Random 不一致？
GTS-Last 下，每个用户的评估目标是其**时间上最后一个**测试交互，偏向最近流行或趋势物品。GTS-Random 下，目标从测试窗口均匀采样，涵盖更广泛的物品流行度。多视图嵌入可能在更难的"预测最后一个物品"任务中有优势；TF-IDF 可能从 Random 更均匀的目标分布中受益。**同一检查点**在 Last 和 Random 下产生不同赢家——这是纯粹的协议效应。

### UniSRec 外部基线
在相同的 GTS-Last + min5 + warm 过滤条件下，UniSRec 在 Beauty（0.0052）和 Toys（0.0041）上得分介于 ID 和 TF 之间，但在 Grocery 上占优（0.0106，接近次优的 2 倍）。NDCG@10 大致与 MRR 排名一致，但 Hit@10 在所有三个数据集上提升了 UniSRec。我们以 MRR 作为主排名指标，报告 NDCG/Hit 作为补充。

## 5 RQ2：时间鲁棒性

### Main vs Early（Table 4，GTS-All）

| 窗口 | TF | LLM | MV |
|------|-------|-------|-------|
| Main | **.0242**±.0010 | .0236±.0006 | .0236±.0012 |
| Early60-EQ | .0180±.0002 | **.0183**±.0002 | .0183±.0002 |

我们使用等 horizon Early 分割 [0.6, 0.1, 0.1]，将验证和测试保持与 Main 相同的 10% 跨度，仅将训练截断从 80% 滑动到 60%。

Table 4 报告的是 GTS-All MRR@10（我们在较小的 60% 截断下使用 All 以最大化每用户信号；主协议仍为 GTS-Last）。所有模型的绝对分数显著下降，但相对排名**不变**：TF、LLM 和 MV 在 Main 和 Early 中都在 0.001 以内。

30–41% 的测试目标是训练中缺失的物品，目标流行度下降（Beauty 中位数 21→15，Toys 18→11）。

**在时间窗口变化后，没有单一文本变体稳健地占优。**

## 6 RQ3：为什么多视图增益有限

### (1) 高视图间 CKA
所有六对 LLM 视图的 CKA ≥ 0.82（Beauty 0.84–0.94；Toys 0.82–0.92）。TF-IDF vs 任何 LLM 视图的 CKA ≈ 0.19–0.20（Beauty）和 0.18–0.19（Toys）——定性上截然不同的区间。

### (2) 成对余弦 vs CKA
提示视图之间的平均成对余弦通常中等或接近零，但 CKA 测量的是跨物品集的 Gram 矩阵几何，而非实例级向量对齐。低余弦 + 高 CKA = "语义释义"的失败模式。

### (3) 拼接视图的低有效秩

| 表征 | 维度 | ER (Beauty) | ER (Toys) |
|------|------|-------------|-----------|
| 单 LLM 视图（均值）| 64 | 63.7 (99.5%) | 63.6 (99.4%) |
| 4 视图拼接 | 256 | 136.1 (**53.2%**) | 141.2 (**55.2%**) |
| TF-IDF (SVD) | 256 | 249.9 (97.6%) | 251.4 (98.2%) |

近一半维度被冗余结构"消耗"。

### (4) LOOV 影响可忽略

| 数据集 | Full MRR | −Desc | −Func | −Aud | −Style |
|--------|----------|-------|-------|------|--------|
| Beauty | .01571 | −.00021 | +.00005 | −.00002 | −.00017 |
| Toys | .01089 | −.00035 | −.00011 | −.00015 | −.00033 |

最大 |Δ| = 0.00035（Toys 描述视图，3.2% 相对变化）。Beauty 上所有 |Δ| ≤ 0.00021（< 1.5%）。

### 冗余来源
- **白化前** (SVD+中心化, 64-d)：Beauty 平均 CKA = 0.96，Toys = 0.96
- **白化后**：Beauty 0.87，Toys 0.86
- **原始 3584-d Qwen 隐层**：Beauty CKA = 0.961，Toys = 0.963；有效秩仅 1567 (10.9%) / 1622 (11.3%)

冗余**内在于 Qwen 编码器的表征中**，不是 SVD 截断的产物。~90% 的维度坍缩在源头就已锁定。

### 综合
分析汇聚：提示视图编码重叠语义，导致维度坍缩和可忽略的单视图贡献。潜在互补性在于词法 TF-IDF 和语义 LLM 之间（CKA ≈ 0.19），暗示多提示堆叠未利用的表征不相似性。

## 7 讨论与局限

### 为什么 TF-IDF 能匹敌多视图 LLM？
两个互补因素：
1. TF-IDF 捕捉**词法多样性**：SVD 投影保留了几乎所有可用容量（ER/dim ≈ 0.98），每个维度贡献真正不同的信息。
2. 四个 LLM 视图受**语义同质性**之苦：相同编码器对同一物品文本用微小指令变化处理，产生高度相似的关系几何（CKA 0.82–0.94），名义上 4 倍维度但实际只增加了约 50% 新容量。

### Pure LLM-only 消融
仅使用单个 Qwen2.5-7B 视图、无 TF-IDF 基础（同架构，同两阶段管线）。GTS-All 下，Pure-LLM 在 Beauty 上达到 MRR@10 = .0113，Toys = .0058——介于 ID-only（.0156/.0118）和标准 LLM 变体（.0236/.0181）之间。TF-IDF 锚定的对齐预热贡献了超越 LLM 嵌入本身的有意义信号。

### TF+LLM 混合消融
使用 MV 架构（TF-IDF 基础 + 单 LLM 视图，无额外提示视图）。GTS-All（3-seed 均值）：

| | Beauty | Toys |
|---|---|---|
| TF+LLM Hybrid | .0203±.0001 | **.0247±.0001** |
| TF（对比） | .0242 | .0191 |
| MV（对比） | .0236 | .0184 |

- **Beauty**：Hybrid (.0203) < TF (.0242)，LLM 视图干扰了 TF 的词法覆盖。
- **Toys**：Hybrid (.0247) >> 所有已有变体，超过 TF +29%。

**表征不相似性是互补性的必要不充分条件**：收益取决于数据集，不能仅从低 CKA 推断。

### 从业者建议
1. 在 GTS 下用明确的目标模式报告文本表征比较。LOO 可能逆转排名。
2. 以截断拟合 TF-IDF 作为强基线起点。
3. 单 LLM 视图通常匹敌四个提示视图；投资多视图管线前先诊断冗余性。
4. TF+LLM 混合可在某些数据集上超越所有单表征变体（Toys +29%），但收益取决于数据集。低 CKA 表示不相似性，不保证互补性。
5. 不要跨协议声称单一"最佳"文本表征；Last 和 Random 并列报告。

### 局限
- **Warm-target 范围**：缺乏内容 zero-shot 回退，排除 30–41% 的真实测试物品。
- **静态元数据**：固定产品标题/描述。
- **仅 Amazon 域**：Grocery 是同平台复制，不是域多样性。
- **冗余定位**：仅测试了 Qwen2.5-7B；其他架构可能有不同的视图间结构。

## 8 结论

我们对序列推荐的文本表征进行了泄漏感知控制研究，定位为实证调查而非模型提案论文。三个结论：

1. **协议很重要。** TF-IDF、单视图 LLM 和多视图的相对排序取决于 GTS 目标模式。GTS-Last 下多视图窄幅领先；GTS-Random 下 TF-IDF 持平或领先——完全由目标选择驱动。

2. **没有文本变体稳健地占优。** 等 horizon Early 窗口下，绝对 MRR 显著下降但文本变体保持在 0.001 以内。

3. **多视图增益受视图间冗余限制。** CKA、有效秩和 LOOV 联合表明提示视图编码重叠语义；潜在互补性在词法和语义特征之间（CKA ≈ 0.19），而非同一编码器的不同提示指令之间。TF+LLM 混合确认这种不相似性可转化为增益（Toys +29%）但也显示干扰（Beauty），低 CKA 是互补性的必要不充分条件。

社区应先锁定时间协议，再诊断表征冗余，然后再投资于额外提示视图或融合模块。实用默认策略：报告 GTS-Last（Random 作为检查），保留截断拟合 TF-IDF 作为必选基线，将多视图 LLM 特征视为待检验假设——而非免费升级。

### 未来方向
1. **鲁棒 TF+LLM 混合融合：** Toys 上 +29% 但 Beauty 上干扰；需跨域和融合架构的进一步研究。
2. **跨架构冗余审计：** 测试 decoder-only vs encoder-only LLM 是否有相同的视图间坍缩。
3. **GTS-Successive 评估**验证 Last/Random 作为在线代理。
4. **非 Amazon 域**测试协议敏感性的泛化性。
5. **指令多样化提示**强制语义分歧以测试互补性是否可在提示层面工程化。
