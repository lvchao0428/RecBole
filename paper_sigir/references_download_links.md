## 如何使用

| 链接类型 | 说明 |
|----------|------|
| **DOI** (`https://doi.org/...`) | 出版社官方解析页；多数机构可下 PDF，无权限时显示摘要或购买页。 |
| **arXiv PDF** | 通常可直接下载，与最终录用版可能略有差异（以出版社版本为准）。 |
| **ACL Anthology** | EMNLP 等 NLP 会议论文开放 PDF。 |
| **PMLR** | ICML 等部分会议论文的官方开放 PDF。 |

## 引用信息核对（`refs.bib` 与常识一致性）

以下为**建议修正或知情保留**项，不影响 DOI 是否有效。

| 问题 | 说明 | 建议 |
|------|------|------|
| **`wu2021cl4rec` 键名与年份** | BibTeX 键暗示 2021 与 “Wu 为首作者”，但条目中 `year = {2022}`、`booktitle = ICDE 2022`，且**第一作者为 Xie, Xu**（Wu 为合作者之一）。论文常称 **CL4Rec**，正式发表为 **ICDE 2022**。 | 正文引用可不变；若重排 bib，宜改为 `xie2022cl4rec` 等与首作者/年份一致，并全局替换 `\cite`。 |
| **`radford2021clip`** | `refs.bib` 未写 DOI；ICML 正式版本以 **PMLR Proceedings** 为准，与 arXiv:2103.00020 为同一工作。 | 已在本文档同时给出 PMLR PDF 与 arXiv PDF；bib 可补 `url = {http://proceedings.mlr.press/v139/radford21a.html}`。 |
| **`wang2017dcn`** | 条目为 ADKDD’17 workshop，bib 中已有 `url = {https://arxiv.org/abs/1708.05123}`。 | 下载 arXiv PDF 合理；若投稿要求写正式页码，需再核 ADKDD 论文集信息。 |
| **`hidasi2016gru4rec`** | ICLR’16；常用 arXiv **1511.06939**。 | 与 bib 中 `url` 一致。 |
| **`huang2025mvcgnn_session`** | 期刊 *Mathematics* (MDPI)，`year = 2025`，`doi = 10.3390/math13091530`。 | 若审稿质疑“过新”，属正常近年文献；题名与作者以 DOI 解析页为准。 |
| **`qwen2024qwen25`** | arXiv **2412.15115**，条目 `year = 2024`，`journal = arXiv preprint`。 | 与常见引用一致；正式发表若更新可再同步 bib。 |
