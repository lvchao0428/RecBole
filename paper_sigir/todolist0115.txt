#   - TF-IDF HR_new < ID-only (Toys: 1.83% < 1.91%)
#   - TF-IDF+LLM ≈ TF-IDF (差异小于 0.5%)

#   2. 对齐损失未针对冷启动物品进行加权
#   3. 推理时未对冷启动物品增强文本特征贡献
#

#   - exp_tfidf_llm_beauty_with_boost.sh: cold=2.0, infer=1.0
#   - 预期: HR_new 提升 5-10%
#
# 修复方案 B: 降低 MV 的 boost (保守)
#   - 将 MV 的 cold=2.5, infer=1.5 降低到 cold=2.0, infer=1.0

#   - 缺点: 可能降低 MV 的 HR_new 优势
