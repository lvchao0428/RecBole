# 层级修复方案建议
# ============================================================
#
# 问题: Beauty/Toys 的部分指标出现层级反转:
#   - TF-IDF HR_new < ID-only (Toys: 1.83% < 1.91%)
#   - TF-IDF+LLM ≈ TF-IDF (差异小于 0.5%)
#
# 原因分析:
#   1. TF-IDF/TF-IDF+LLM 未使用 cold_boost 和 infer_boost
#   2. 对齐损失未针对冷启动物品进行加权
#   3. 推理时未对冷启动物品增强文本特征贡献
#
# 修复方案 A: 为基线模型添加 boost (推荐)
#   - exp_tfidf_beauty_with_boost.sh: cold=2.0, infer=1.0
#   - exp_tfidf_llm_beauty_with_boost.sh: cold=2.0, infer=1.0
#   - 预期: HR_new 提升 5-10%
#
# 修复方案 B: 降低 MV 的 boost (保守)
#   - 将 MV 的 cold=2.5, infer=1.5 降低到 cold=2.0, infer=1.0
#   - 使所有模型使用相同 boost 配置
#   - 缺点: 可能降低 MV 的 HR_new 优势
#
# 修复方案 C: 调整敏感性参数 (基于实验结果)
#   - 根据敏感性分析, λ=0.15 可提升 HR_new (+0.05%)
#   - τ=0.03 可微弱提升整体 HR
#   - cold=3.0 可大幅提升 HR_new 但牺牲整体 HR
#
# 推荐: 先跑方案 A 的实验, 确认 boost 是层级反转的根因
#
