\title{Multi-View Text Features for Sequential Recommendation:\\
Explicit Cross and Alignment for Reliable Full-Ranking Gains}

% Review version: anonymous authors.

\begin{abstract}
% 五句法: 背景-痛点-方案-结果-洞察
Text features serve as a widely adopted plug-in for sequential recommenders, bridging collaborative signals with semantic understanding.
%
However, conventional single-view \llm embeddings offer limited exploitation of textual semantics, and sampled evaluation protocols (e.g. uniform-100 negatives, a.k.a.\ uni100) often disagree with full-ranking metrics---particularly for cold-start items---potentially misleading model selection.
%
We propose \model, a plug-and-play framework that systematically addresses these challenges through multi-view text representations (normalized and whitened for decorrelation), explicit ID$\times$Text cross interactions via DCN-V2, and contrastive alignment with cold-start reweighting.
%
Under full-ranking evaluation on Amazon Beauty and Toys\&Gam-es, \model achieves HR@10 of 6.07\% and 6.92\% respectively, with substantial cold-start improvements (HR\_new@10 up to 1.99-\%, HR\_few@10 up to 5.22\%).
%
We reveal an HR--ranking trade-off that guides when a frugal \tfidf-only configuration suffices versus when stronger multi-view features pay off; hyperparameter sensitivity and seed stability analyses are provided in the appendix.
\end{abstract}
