标题：面向序列推荐的多视角文本特征：显式交叉与对齐以实现可靠的全排序收益
================================================================================

【摘要】

基于文本特征的序列推荐模型受到越来越多关注，但已发表结果难以横向比较：单视角嵌入、不一致的评估协议（采样负例 vs. 全排序），以及未报告的配置细节都会损害可复现性，并可能误导模型选择。

本文提出 MV-Align：一个完全开源、即插即用的框架，结合多视角文本表示（TF-IDF 与 LLM，并对各视角分别白化以去相关）、通过 DCN-V2 实现的显式 ID×文本交叉交互，以及带冷启动重加权的对比对齐损失。整条流水线以 RecBole 为基础，以「一条命令即可复现」的形式发布。

在 Amazon Beauty 与 Toys&Games 上的全排序评估中，MV-Align 取得 HR@10 为 5.79% 与 6.61%（相对纯 ID 分别为 +6.8% 与 +11.7%），而仅 TF-IDF 已构成强基线（HR@10 分别为 +2.6% 与 +6.3%）。通过对对比学习与冷启动超参数的受控消融，我们揭示了由交叉网络主导的 HR 与排序指标之间的权衡，并表明在嵌入带宽相同的前提下，多视角提示相对所有文本基线均能改善冷启动物品的排序质量。

复现本文报告结果所需的全部代码与配置文件见：https://anonymous.4open.science/r/recbole-multiview-D83A

【关键词】

序列推荐；可复现性；文本特征；多视角表示；全排序评估；开源基准


================================================================================
一、引言
================================================================================

现代序列推荐模型（如 SASRec）为建模用户行为序列提供了强骨干，但现实目录中冷启动与长尾物品占主导，协同信号稀疏。物品文本（标题、描述、评论）可提供语义线索以改善泛化，但也带来工程上的张力：轻量特征（如 TF-IDF）成本低且往往出人意料地强，而 LLM 嵌入可能更丰富，但在抽取、存储与在线服务上昂贵得多。

在大规模推荐中，团队通常沿三条轴控制成本：可训练参数与优化器状态（显存）、前向 FLOPs 或实测延迟（推理）、以及文本的离线预处理（如一次性编码器运行），后者在目录上摊销，且与单次请求的服务相分离。

我们在 Beauty 配置下报告可训练参数与框架估计的 FLOPs（见文中参数表），作为运行时成本的可比代理；并在「模型复杂度」一节讨论离线 LLM 视角编码相对单视角的开销。

两项实践观察驱动本文工作。第一，一旦建立较强的 TF-IDF 基线（例如在 Beauty 全排序下 HR@10 +2.6%、NDCG@10 +25.9%），再叠加 LLM 特征的边际收益可能较小且依赖领域，从而难以判断多视角提示是否值得额外的离线编码与适度的可训练增量开销。第二，工业界模型选择常依赖快速采样评估（如 uniform-100 负例），但采样指标可能与全排序指标不一致，甚至排错模型顺序；当改进集中在冷启动/长尾层时，这种错配尤其有害。

MV-Align 用简单的「准备—交互—对齐」配方应对上述矛盾（见框架图）：

(1) 准备（表示层）：我们对每个文本视角分别归一化与白化，以应对三类失效模式——视角间尺度不匹配、视角间相关、以及跨视角冗余。白化使多视角通道去相关，使后续交互更易学习。

(2) 交互（融合层）：我们使用显式交叉网络（DCN-V2）学习高阶 ID×文本特征交叉。Transformer 自注意力建模序列级物品—物品依赖，但并不显式捕获 ID 嵌入与文本嵌入之间的特征级交互；DCN-V2 通过由可学习权重矩阵门控的元素乘积填补这一缺口。

(3) 对齐（目标层）：我们通过 InfoNCE 对比损失将各文本视角对齐到协同 ID 嵌入空间。对齐方向为（文本视角 → ID 空间）；正样本对为（该物品的文本视角，该物品的 ID 嵌入）；负样本为批次内其他物品。冷启动重加权避免高频物品主导对齐信号，使低流行度物品获得足够的梯度更新。

本文贡献有三：(i) 提出面向 SASRec 的可部署插件框架 MV-Align，在固定嵌入预算下既支持经济的仅 TF-IDF 配置，也支持更强的多视角 LLM 特征；(ii) 在两个 Amazon 领域上以全排序评估与按流行度分层分析（主表中突出「new」层）进行基准测试，并提供系统性消融（白化、SE 式门控、交叉）以及鲁棒性分析（超参敏感度/稳定性）；(iii) 不仅报告收益，还解释关键现象：白化与显式交叉可提升排序质量（MRR/NDCG）同时略损召回（HR），揭示 HR—排序权衡，以指导何时选择轻量配置与更强配置。

围绕四个研究问题组织：RQ1 每视角白化是否改善文本特征质量？RQ2 SE 式通道门控是否有帮助？RQ3 在嵌入带宽相同时，多视角是否优于单视角？RQ4 显式交叉与对比对齐各自的贡献是什么？


================================================================================
二、相关工作
================================================================================

【序列推荐】Transformer 序列模型如 SASRec、BERT4Rec（双向掩码预测）是捕获用户行为模式的强骨干。GRU4Rec 开创 RNN 会话建模；SASRec 将自注意力用于下一物品预测与因果掩码。高效变体包括 LightSANs 等。

【文本增强推荐】物品文本（词袋、神经编码器或 LLM 嵌入）提供协同过滤之外的互补信号。早期工作使用 TF-IDF、Item2Vec；CDL 通过堆叠去噪自编码器联合建模文本。近期方法利用预训练语言模型：UniSRec 使用 BERT 编码物品文本作为可迁移表示；VQ-Rec 通过向量量化桥接语言与协同语义。大语言模型进一步拓展该方向：P5 以 text-to-text 统一推荐；TALLRec 通过指令微调对齐 LLM 与推荐。这些方法通常以单一提示或表示编码物品文本。本文探索通过多样化提示视角（身份、功能、受众、类别）得到的多视角 LLM 嵌入，配合显式融合与对齐，并说明相对更简单方案何时值得增加复杂度。

【特征交互与交叉网络】Deep & Cross Network（DCN）及 DCN-V2 显式建模特征交叉，补充 DNN 学到的隐式交互。Squeeze-and-Excitation（SENet）引入通道注意力；FiBiNET 将 SENet 适配 CTR。交叉网络在 CTR 中有效；本文将其适配于序列场景下的 ID–文本融合，并对 LLM 特征使用 SE 式块做每视角通道门控。

【推荐中的多视角学习】多视角学习利用不同特征源或模态的互补信息。受 CLIP 通过对齐视觉与文本的对比学习启发，我们设计多视角提示以从语言模型中引出多样语义。会话推荐中也有多视角图神经方法；本文将多视角学习应用于 LLM 文本嵌入，在不同提示视角与白化去相关后再融合。

【推荐中的对比学习】InfoNCE 等对比目标广泛用于自监督表示学习；推荐中常用于跨视角对齐用户/物品表示。本文将其扩展为多视角文本到 ID 的对齐，并加入冷启动重加权。

【评估协议】采样评估可能误导模型选择；全排序评估更可靠但计算昂贵。本文采用全排序并结合分层分析以理解不同流行度层上的行为。


================================================================================
三、方法
================================================================================

框架含三个关键部分：(1) 归一化与白化；(2) 通过 DCN-V2 捕获显式 ID×文本交互的交叉网络；(3) 使用带冷启动重加权的 InfoNCE 将多视角文本与 ID 嵌入对齐。

【骨干：带文本融合的 SASRec】用户交互序列记为 s_u = [i_1,…,i_n]，最大长度 L。SASRec 用 Transformer 将序列编码为表示 h_u。每个物品 i 有 ID 嵌入 e_i。我们用文本特征增强物品并融合为用于打分的融合物品嵌入 \tilde{e}_i。

【多视角文本表示】假设轻量 TF-IDF 嵌入 t_i^(0) 为基视角，另有 V 个 LLM 提示视角 {t_i^(v)}（如身份/功能/受众/类别），d_t、d_l 分别为 TF-IDF 与原始 LLM 嵌入维度。

— 每视角白化：多视角 LLM 嵌入存在三类问题：(i) 尺度不匹配；(ii) 视角相关；(iii) 跨视角冗余。先将各 LLM 视角从 d_l 经截断 SVD 降至 d_v 维，再对各视角独立做 ZCA 白化。给定全体物品在视角 v 上的矩阵 X^(v)，计算去均值、协方差、白化（加 εI 稳定）；白化统计在训练集上离线计算，训练/推理时固定。每视角独立白化参数，比跨视角共享白化更能保留视角语义。

— SE 式通道门控：受 SENet 启发，对每个投影后的嵌入用 MLP 门控（适合逐物品表示，不在物品间池化）。白化视角投影到骨干维度 d 后经门控精炼。

— 每视角 ℓ2 归一化：门控后对每视角独立做 ℓ2 归一化，保证各视角对融合的贡献尺度可比并稳定后续交叉网络学习。

— 视角门控与融合：为每个视角学习标量门 g_v=σ(θ_v)∈(0,1)，不做跨视角归一化。所有视角（及可选 TF-IDF 基）拼接后投影回 R^d，得到 t_i。

【显式交叉融合】除依赖自注意力外，引入基于 DCN-V2 的显式交叉模块。拼接 x_i=[e_i; α_i t_i]，交叉层按 DCN-V2 全秩（非 mix）形式更新；交叉输出与浅层 MLP 经预测层得到 \tilde{e}_i。标量 α_i∈(0,1) 含全局文本门与可选每物品门控，并用温度缩放以稳定融合。

【多视角对比对齐】用 InfoNCE 将各文本视角对齐到 ID 空间；正样本为（物品文本视角，该物品 ID）；负样本为批次内物品。对批次 B 定义 ID 与文本视角的余弦相似度矩阵，带温度 τ；按视角加权组合各视角对齐损失。

冷启动：训练时对样本按物品流行度 pop(i) 重加权 w_i，使低流行物品在对齐中获得更大权重；推理时对低流行物品动态放大文本权重 γ_i，使有效 α_i' = α_i·γ_i，便于部署时调节而无需重训。

【训练目标】L = L_rec + λ·L_mv-align，其中 L_rec 为标准序列推荐损失（采样正负的交叉熵）。

【模型复杂度】离线：TF-IDF 与 LLM 嵌入预计算；SVD 与白化在训练集离线完成；每 LLM 视角需对每件物品单独编码，离线成本大致随视角数增长，但不增加单次请求延迟。在线：每视角投影、一层 DCN-V2 交叉、融合 MLP；文中表格报告 Beauty 上可训练参数与单次前向 FLOPs。

【两阶段训练】Phase-A：冻结骨干，以较高学习率训练文本头与交叉模块，在验证集上网格搜索 (λ,τ)；Phase-B：解冻全部参数，分组学习率联合微调。


================================================================================
四、实验
================================================================================

【数据与评估】Amazon Beauty 与 Toys&Games；时间划分；在 K∈{5,10,20} 下报告全排序指标。除整体 HR、NDCG、MRR、Precision 外，按训练集中物品交互次数分层：new [1,3)、few [3,10)、frequent [10,∞)。主表报告整体与 new 层；正文仅给全排序指标。评估为留一法的下一物品预测，每测试例一个真值；HR@K、Hit@K、Recall@K 在此设定下一致，文中用 HR@K 简称，MRR/NDCG 表征排序位置质量。

【基线】(1) SASRec 纯 ID；(2) SASRec+TF-IDF（预计算 TF-IDF，含显式交叉与对齐）；(3) SASRec+TF-IDF+LLM 单视角（Qwen2.5-7B 单嵌入，SE 门控与对齐）；(4) MV-Align 多视角（TF-IDF + 4 个 LLM 提示视角，每视角 SE、显式交叉、多视角对齐）。

【实现细节】嵌入维度 d=256，最大序列长度 L=50，2 层 Transformer、2 头，batch 512，Adam 基础学习率 1e-4。两阶段：Phase-A 15 epoch → Phase-B 50 epoch；Phase-A 在 MRR@10 上选 (λ,τ)。主跑使用 Balanced：λ=0.10，τ=0.05，训练重加权 β=3.0，推理 boost β_infer=0.6。每配置 4 个随机种子 {2024–2027}，报告 mean±std。基于 RecBole；配置与脚本随制品发布。

【参数表】Beauty 上多视角相对纯 ID 约 +1.8M 可训练参数；LLM 嵌入为离线缓冲，不计入可训练参数。


================================================================================
五、主要结果
================================================================================

全排序下，加文本特征一致优于纯 ID；TF-IDF 带来可观提升（Beauty HR@10 +2.6%，Toys +6.3%）。MV-Align（7B）在两数据集上整体最优：Beauty HR@10=5.79%（+6.8%），Toys HR@10=6.61%（+11.7%）；层次为 MV-Align > TF-IDF+LLM > TF-IDF > 纯 ID。

对 new 层：MV-Align 相对文本基线有明显提升；在 Beauty 上缩小与纯 ID 的 HR_new 差距（1.76% vs 1.88%），在 Toys 上超过纯 ID（2.04% vs 1.92%）。MV-Align 在两数据集上 new 层的 NDCG@10、MRR@10 最佳，表明更丰富的多视角文本主要改善冷启动物品的排序质量，而召回覆盖仍对融合配置敏感。

【主表数值摘要——Amazon Beauty】
纯 ID：HR@10 5.42±0.21，NDCG@10 2.93±0.05，MRR@10 2.14±0.01；new 层 HR 1.88±0.03 等。
+TF-IDF：HR@10 5.56±0.03，NDCG@10 3.69±0.02 …
+TF-IDF+LLM(7B)：HR@10 5.62±0.03 …
MV-Align(7B)：HR@10 5.79**±0.04，NDCG@10 3.80**±0.02，MRR@10 3.19*±0.02；new 层 HR@10 1.76±0.05 等。

【Amazon Toys&Games】类似结构；MV-Align HR@10 6.61** 等。（表中 * p<0.05，** p<0.01，相对最强基线的配对 t 检验。）

【LLM 提示模板】单视角：「[TITLE] {text}」。多视角四条：身份/标题、功能、目标受众、类别/上下文（英文模板见原文）。每视角独立编码，SVD 至 64 维，再经每视角 SE 门控后融合。


================================================================================
六、分析
================================================================================

消融均在 Toys&Games 7B 上进行。

【组件消融】白化（RQ1）：多视角下去白化降低 HR@10；单视角下去白化影响小。SE 门控（RQ2）：单独去掉 SE 多数指标边际变化；同时去掉 SE 与 Cross 时 HR_new 变化大，表明二者共同校准向高频。交叉（RQ4）：去掉交叉使 HR@10 升高但 MRR/NDCG 明显下降——揭示 HR 与排序指标的权衡；无交叉时分数分布更「平」，覆盖好但顶部分辨差。对齐（RQ4）：去掉多视角 InfoNCE 对齐降低整体与 new 的 HR，对 NDCG/MRR 略降，主要在 new 层可见，且不像交叉那样出现 HR—排序反转。

【RQ3】在相等带宽下（单视角 256 维 LLM vs 多视角 4×64=256），多视角在两数据集上全面优于单视角，在 new 层增益最明显。

【HR—排序权衡机制】交叉网络产生更「尖」的分数分布，利于 top-1（MRR）但可能使相关物品刚好落在 top-K 外；去掉交叉则分布更平滑，HR 升而 MRR/NDCG 降。实践：候选生成/重召回可向禁用交叉；最终精排可启用交叉。

【超参敏感度】λ、τ、β、β_infer 在默认附近整体 HR@10、NDCG@10 变化幅度小，默认配置接近最优，便于实际调参。


================================================================================
七、结论
================================================================================

本文提出 MV-Align：完全开源、即插即用的文本增强序列推荐框架，以 RecBole 上单命令可复现包发布。Beauty 与 Toys 全排序实验给出三条可操作建议：

(1) TF-IDF 是出人意料地强的基线（Beauty/Toys 上 HR@10 相对纯 ID +2.6%/+6.3%），在投资 LLM 嵌入前应作为第一步文本增强。

(2) 在相等嵌入带宽下，多视角 LLM 提示改善文本基线，并在 new 层上取得最强 NDCG/MRR；Beauty 上缩小 HR_new 与纯 ID 的差距，Toys 上超过纯 ID。

(3) 交叉网络主导 HR 与 MRR/NDCG 的权衡：启用交叉提升排序精度、略损 HR；禁用则相反。可直接映射到部署：候选阶段可关交叉，最终重排可开交叉。
