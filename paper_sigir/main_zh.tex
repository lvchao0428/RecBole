\begin{abstract}
文本特征是序列推荐模型中最常用的插件之一，为协同信号提供语义补充。
然而，多视图 \llm 嵌入相比更简单的方案（\tfidf、单视图 \llm）的边际收益往往较小且因领域而异，使得"何时值得增加复杂度"成为悬而未决的问题。
更复杂的是，采样评估（如 uniform-100 负采样）可能与全排序指标不一致，尤其在冷启动物品上，进而可能误导模型选择。
为此，我们提出 \model（MV-Align），将多视角文本表示进行归一化/白化，并通过显式 cross 模块建模高阶 ID--文本交互，同时以对比学习将各视图对齐到协同 ID 空间并对冷启动样本重加权。
在 Amazon Beauty 与 Toys\&Games 上的全排序评估中，\model 的 HR@10 分别达到 6.22\% 与 7.02\%，并在冷启动分层上进一步提升（例如 HR\_new@10 最高 2.37\%，HR\_few@10 最高 5.55\%）。
我们揭示了 HR 与排序指标（MRR/NDCG）之间的权衡，并给出何时选择轻量 \tfidf 配置、何时上多视角 \llm 强配置的实践建议；同时在附录报告超参数敏感性与稳定性分析。
\end{abstract}

\section{引言}

诸如 \base~\cite{kang2018sasrec} 等序列推荐模型已成为建模用户行为序列的强大骨干网络，但真实工业场景中大量物品处于冷启动/长尾状态，协同信号稀疏，泛化困难。
物品文本（标题、描述、评论）能提供语义线索并缓解该问题，但也带来了典型矛盾：轻量特征（如 \tfidf）成本低且效果出奇地强，而 \llm 衍生嵌入语义更丰富，却在离线提取、存储与在线服务上成本更高。

本工作由两个实践观察驱动。
其一，在强 \tfidf 基线已经建立之后（例如 Beauty 全排序下 HR@10 与 NDCG@10 分别提升 +27.5\% 与 +40.9\%），再叠加 \llm 特征的边际收益往往更小且具有领域依赖性，使得“多视角提示是否值得”变得不清晰。
其二，工业中模型选择常依赖快速的采样评估（uniform-100 负采样，亦称 uni100），但采样指标可能与全排序不一致并导致模型排序错误~\cite{krichene2020sampledmetrics}；当改进主要集中在冷启动/长尾分层时，这种不一致的代价尤为明显。

\model 以“先处理、再交互、再对齐”的方式化解上述矛盾。
我们首先对每个文本视角做归一化并进行白化，以处理尺度不一致并降低跨视角冗余相关性；
随后引入显式 cross 模块（DCN-V2）来学习超越自注意力的高阶 ID$\times$Text 交互；
最后用对比学习将各文本视角对齐回协同 ID 空间，并对冷启动样本重加权，避免对齐信号被高频物品主导。

我们的贡献主要包括三点：
\begin{itemize}[leftmargin=*,itemsep=1pt]
  \item 提出 \model，一个可部署的 \base 插件框架，既支持节约型的 \tfidf-only 配置，也支持在固定嵌入预算下更强的多视角 \llm 特征。
  \item 在 Amazon Beauty 与 Toys\&Games 上采用\textbf{全排序}与流行度分层指标进行评测，并给出系统消融（白化、SENet、cross）与稳健性分析（附录中的超参数敏感性/稳定性）。
  \item 不仅报告增益，还解释一个关键现象：白化与显式 cross 往往提升排序质量（MRR/NDCG）但可能轻微降低召回（HR），从而形成 HR--排序 指标的权衡，并据此给出何时选择轻量方案、何时采用强配置的实践建议。
\end{itemize}
本文其余部分组织如下：我们回顾相关工作，介绍 \model 与两阶段训练协议，展示全排序结果与消融实验，并给出分析与结论。

\section{相关工作}
\paragraph{序列推荐}
基于 Transformer 的序列模型如 \base~\cite{kang2018sasrec} 和 BERT 风格目标~\cite{sun2019bert4rec} 是捕获用户行为模式的强大骨干。
GRU4Rec~\cite{hidasi2015gru4rec} 开创了基于 RNN 的会话建模，而 SASRec 引入了带因果掩码的自注意力进行下一物品预测。
% [可扩展] 更多序列推荐相关工作

\paragraph{文本增强推荐}
物品文本特征（来自词袋、神经编码器或 \llm 嵌入）提供了协同过滤之外的补充信号。
早期工作使用 TF-IDF 和 word2vec 进行物品表示；近期方法利用预训练语言模型（BERT、GPT）获取更丰富的语义。
% [可扩展] 文本增强推荐相关工作

\paragraph{特征交互与交叉网络}
Deep \& Cross Network (DCN)~\cite{wang2017dcn} 及其后续 DCN-V2~\cite{wang2021dcnv2} 显式建模特征交叉，补充 DNN 学习的隐式交互。
在推荐中，交叉网络在 CTR 预测中展示了有效性；我们将其适配用于序列设置中的 ID-文本融合。

\paragraph{推荐中的对比学习}
对比目标如 \InfoNCE~\cite{oord2018cpc} 已被广泛用于自监督表示学习。
在推荐中，对比方法跨视图对齐用户/物品表示~\cite{wu2021cl4rec}。
我们将其扩展到多视图文本-ID对齐。

\paragraph{评估协议}
采样评估可能误导模型选择~\cite{krichene2020sampledmetrics}；全排序评估提供更可靠的比较但计算开销大。
我们采用带分层分析的全排序以理解模型在不同流行度分层上的行为。

\section{研究问题}
我们围绕以下研究问题组织研究，重点关注\textbf{消融实验}以理解每个组件何时以及为何有帮助：

\begin{itemize}[leftmargin=*,itemsep=3pt]
  \item \textbf{RQ1（白化效果）} 白化（vs. 仅L2归一化）是否改善单视图和多视图设置下的文本/\llm 特征质量？
  
  \item \textbf{RQ2（SENet通道注意力）} SENet门控是否为文本特征提供有效的通道注意力？我们比较有/无SENet的单视图和多视图。
  
  \item \textbf{RQ3（等带宽下多视图 vs. 单视图）} 给定相同的总嵌入维度（如单视图256维 vs. 多视图 $4\times 64$维），多视图提示是否优于单视图？我们关注 HR@K、NDCG@K、MRR@K，特别是\textbf{new}和\textbf{few}物品分层（冷启动物品）。
  
  \item \textbf{RQ4（Cross和Align消融）} 显式交叉融合和多视图对齐的单独和组合贡献是什么？我们消融：
  \begin{itemize}[leftmargin=*,itemsep=1pt]
    \item 多视图 + cross + align（完整模型）
    \item 多视图 + cross（无align）
    \item 多视图 + align（无cross）
    \item 仅多视图（无cross，无align）
  \end{itemize}
\end{itemize}

\section{方法}
\subsection{骨干网络：带文本融合的 SASRec}
设用户交互序列为 $s_u = [i_1,\dots,i_T]$，最大长度为 $L$。
\base 通过 Transformer 将 $s_u$ 编码为序列表示 $\mathbf{h}_u \in \mathbb{R}^d$。
每个物品 $i$ 有一个 ID 嵌入 $\mathbf{e}_i \in \mathbb{R}^d$。
我们用文本特征增强物品，并将它们融合成用于打分的\emph{融合物品嵌入} $\tilde{\mathbf{e}}_i$。

\subsection{多视图文本表示}
我们假设有一个轻量级 \tfidf 嵌入 $\mathbf{t}_i^{(0)}$ 作为基础视图，以及 $V$ 个 \llm 提示视图 $\{\mathbf{t}_i^{(v)}\}_{v=1}^V$（如身份/功能/受众/类别视图）。
每个视图被投影到骨干维度，并通过压缩激励（SENet）门控进行精炼：
\begin{align}
  \mathbf{z}_i^{(v)} &= \mathbf{W}_v \mathbf{t}_i^{(v)} \in \mathbb{R}^d,\\
  \mathbf{r}_i^{(v)} &= \mathbf{z}_i^{(v)} \odot \sigma(\mathrm{MLP}_v(\mathbf{z}_i^{(v)})).
\end{align}
在 \model 中我们应用\emph{逐视图} $\ell_2$ 归一化：
\begin{equation}
  \hat{\mathbf{r}}_i^{(v)} = \frac{\mathbf{r}_i^{(v)}}{\lVert \mathbf{r}_i^{(v)} \rVert_2}.
\end{equation}
我们为每个视图学习一个标量门控 $g_v=\sigma(\theta_v)\in(0,1)$，且\emph{不}强制跨视图归一化（每个视图独立贡献 $0$--$1$）。
所有视图（可选包括 \tfidf 基础视图）被拼接并投影回 $\mathbb{R}^d$：
\begin{equation}
  \mathbf{t}_i = \mathbf{P}\Big[\mathbf{t}_i^{(0)};\; g_1\hat{\mathbf{r}}_i^{(1)};\; \dots;\; g_V\hat{\mathbf{r}}_i^{(V)}\Big].
\end{equation}

\subsection{显式交叉融合}
我们不仅仅依赖自注意力来捕获协同信号和文本信号之间的高阶交互，而是引入基于 DCN-V2~\cite{wang2021dcnv2} 的\emph{显式交叉}模块。
给定拼接特征 $\mathbf{x}_i=[\mathbf{e}_i;\alpha_i \mathbf{t}_i]$，交叉层更新为
\begin{equation}
  \mathbf{x}^{(l+1)} = \mathbf{x}^{(l)} + \mathbf{x}^{(0)} \odot (\mathbf{W}_l\mathbf{x}^{(l)} + \mathbf{b}_l),
\end{equation}
并与浅层 MLP 结合产生融合嵌入 $\tilde{\mathbf{e}}_i$。
标量 $\alpha_i$ 包含全局文本门控和可选的逐物品门控；它还通过温度相关因子进行缩放以实现稳定融合。

\subsection{多视图对比对齐}
我们使用 \InfoNCE~\cite{oord2018cpc} 将每个文本视图与 ID 嵌入空间对齐。
对于一批正样本物品 $\{i\}_{i=1}^B$，定义相似度矩阵
$\mathbf{S}_{ij} = \mathrm{cos}(\mathbf{e}_{i}, \hat{\mathbf{r}}_{j}^{(v)})$ 和温度 $\tau$。
逐视图对齐损失为：
\begin{equation}
  \mathcal{L}_{\text{align}}^{(v)} =
  \frac{1}{B}\sum_{i=1}^{B}
  -\log \frac{\exp(\mathbf{S}_{ii}/\tau)}{\sum_{j=1}^{B}\exp(\mathbf{S}_{ij}/\tau)}.
\end{equation}
我们学习视图权重 $\pi_v=\mathrm{softmax}(\boldsymbol{\phi})_v$ 并通过 $s_{\text{mv}}$ 缩放总对齐：
\begin{equation}
  \mathcal{L}_{\text{mv-align}} = s_{\text{mv}}\sum_{v=1}^{V}\pi_v \mathcal{L}_{\text{align}}^{(v)}.
\end{equation}

\paragraph{冷启动重加权}
为避免对齐被高频物品主导，我们根据物品流行度 $\mathrm{pop}(i)$ 对样本进行重加权：
\begin{equation}
  w_i = 1 + \beta\cdot \max\Big(0, \frac{T-\mathrm{pop}(i)}{T}\Big),
\end{equation}
并在相似度矩阵上计算加权交叉熵（由 $\sum_i w_i$ 归一化）。

\subsection{训练目标}
我们优化：
\begin{equation}
  \mathcal{L} = \mathcal{L}_{\text{rec}} + \lambda \cdot \mathcal{L}_{\text{mv-align}},
\end{equation}
其中 $\mathcal{L}_{\text{rec}}$ 是标准的序列推荐损失（训练中对采样的正负样本进行交叉熵），$\lambda$ 是对齐权重。

\subsection{模型复杂度}
我们分析每个模型变体的空间（参数）和时间复杂度，遵循~\cite{kang2018sasrec}中的分析。

\paragraph{空间分解}
\base 骨干贡献 $O(|I|d)$ 用于物品嵌入，$O(Ld)$ 用于位置嵌入，$O(d^2)$ 用于 Transformer 编码器参数（自注意力 $Q,K,V,O$ 投影和逐点 FFN 层；层数是一个小常数）。
文本变体添加与文本特征维度成比例的投影层：\tfidf 添加 $O(d_t d)$，单视图 \llm 添加 $O((d_t + d_l)d)$，多视图添加 $O(V d_v d)$ 用于逐视图投影和 SENet 模块，加上 $O(d_t d)$ 用于基础视图。
交叉层每层贡献 $O(Cd^2)$，但由于 $C$ 是一个小常数（通常为1），我们将其吸收到 $O(d^2)$ 项中。

\paragraph{时间分解}
Transformer 自注意力层花费 $O(L^2d)$ 计算 $L\times L$ 注意力矩阵，加上 $O(Ld^2)$ 用于逐点 FFN。
全排序打分增加 $O(|I|d)$ 用于计算所有物品的 logits。
文本模型产生额外的融合开销：
\begin{itemize}[leftmargin=*,itemsep=1pt]
  \item \textbf{\tfidf}：文本投影 $O(|I| \cdot d_t \cdot d)$ 和所有物品的交叉网络融合 $O(|I| \cdot d^2)$。
  \item \textbf{单视图}：由于输入维度更大，投影成本增加到 $O(|I| \cdot (d_t + d_l) \cdot d)$。
  \item \textbf{多视图}：逐视图 SENet 和投影 $O(V \cdot |I| \cdot d_v \cdot d)$ 加上拼接投影 $O(|I| \cdot Vd \cdot d)$。
\end{itemize}
对齐损失为每个视图增加 $O(B^2 d)$ 用于 InfoNCE 相似度矩阵计算。
注意 \llm 嵌入是\emph{离线预计算}并作为静态缓冲区存储的；在线推理成本主要由投影和交叉层决定，而非 \llm 编码器。

\section{两阶段训练协议}
我们使用两阶段训练协议，从一开始就联合学习文本表示和骨干网络：
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{A阶段（文本预热）} 同时初始化骨干和文本模块；冻结骨干，以较高学习率（$\text{lr}_{\text{text}}=1\times10^{-3}$）训练文本头和交叉模块；通过验证指标网格搜索 $(\lambda,\tau)$。
  \item \textbf{B阶段（联合微调）} 解冻骨干并使用分组学习率（文本头、交叉/DNN、骨干）微调所有参数。
\end{itemize}
\paragraph{为何不使用纯 ID 预热？}
消融实验表明，在引入文本特征之前单独预训练 ID 骨干会导致次优结果：ID 嵌入会对协同信号过拟合，使得 A 阶段文本特征难以贡献有效梯度。
从第 0 个 epoch 开始同时使用双模态，文本头能获得更强的学习信号（更高的有效学习率），从而收敛到更好的表示。

\begin{algorithm}[t]
\caption{两阶段训练（A阶段 + B阶段）}
\label{alg:two-phase}
\begin{algorithmic}[1]
\Require 数据集 $\mathcal{D}$；骨干 $\base$；文本特征；网格 $\Lambda,\mathcal{T}$
\State \textbf{A阶段：}冻结骨干参数；对 $(\lambda,\tau)\in \Lambda\times\mathcal{T}$ 训练文本头和交叉模块；在验证集上选择最佳
\State \textbf{B阶段：}加载最佳A阶段检查点；解冻骨干；使用分组学习率微调
\end{algorithmic}
\end{algorithm}

\section{实验}
\subsection{数据集和评估}
我们在两个亚马逊领域进行评估：\textbf{美妆}和\textbf{玩具游戏}。
我们遵循时间顺序划分，并报告 $K\in\{5,10,20\}$ 下的\textbf{全排序}指标。
除了标准指标（召回率、NDCG、MRR、命中率、精确率），我们还报告按物品交互次数的\textbf{流行度分层}指标：
\begin{itemize}[leftmargin=*,itemsep=1pt]
  \item \textbf{new}：$[1,3)$ 次交互
  \item \textbf{few}：$[3,10)$ 次交互
  \item \textbf{frequent}：$[10,\infty)$ 次交互
\end{itemize}
流行度分层按训练集中的物品交互次数统计。
为保证评测的可比性与部署相关性，正文以全排序指标为主，未在主文汇报 uni100 等采样评测；附录~\ref{app:sampled} 提供采样评测与全排序的一致性 sanity check（后续补全）。
我们的评测采用 leave-one-out 的 next-item 设定（每个测试样本只有 1 个 ground-truth），因此 HR@K、Hit@K 与 Recall@K 数值等价；我们在正文中以 HR@K 表示命中/召回，并用 MRR/NDCG 反映靠前位置的排序质量。

\subsection{基线}
我们比较四种主要配置（对应我们的运行脚本）：
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{\base（仅ID）} 不带文本/交叉/对齐的纯序列基线。（\texttt{run50epBase\_stratified.sh}）
  \item \textbf{\base + \tfidf} 使用预计算 \tfidf 嵌入、显式交叉和对齐的轻量级文本基线。（\texttt{two\_phase\_run\_tfidf\_stratified.sh}）
  \item \textbf{\base + \tfidf + \llm（单视图）} 添加与 \tfidf 拼接的单个 \llm 嵌入（Qwen2.5-7B），使用 SENet 门控和对齐。（\texttt{two\_phase\_run\_tfidf\_llm\_stratified.sh}）
  \item \textbf{\model（多视图）} \tfidf 基础视图 + 4个多视图 \llm 提示嵌入（身份/功能/受众/类别），带逐视图 SENet、显式交叉和多视图对比对齐。（\texttt{two\_phase\_run\_multiview\_v2\_stratified.sh}）
\end{itemize}
我们还包括代表性的序列基线（如 BERT4Rec~\cite{sun2019bert4rec}、S3-Rec~\cite{zhou2020s3rec}）和轻量级文本编码器作为额外比较。

\subsection{实现细节}
除非另有说明，我们使用嵌入维度 $d=256$，最大序列长度 $L=50$，2层 Transformer 带2个头，批次大小512，Adam 优化器基础学习率 $10^{-4}$。

\paragraph{两阶段计划}
我们遵循 A阶段（15个 epoch）$\rightarrow$ B阶段（50个 epoch），A阶段在美妆数据上通过 \texttt{MRR@10} 选择 $(\lambda,\tau)$，在玩具游戏上通过 \texttt{HR@10}。
我们使用分组学习率：$\text{lr}_{\text{text}}=1\times10^{-3}$ 用于文本头，$\text{lr}_{\text{cross}}=5\times10^{-4}$ 用于交叉/DNN 块，$\text{lr}_{\text{backbone}}=\text{lr}_{\text{text}}\times 0.1$ 在B阶段。

\paragraph{网格}
对于主要实验，我们在美妆上使用 $\lambda\in\{0.03\}$ 和 $\tau\in\{0.1\}$，在玩具游戏上使用 $\lambda\in\{0.05\}$ 和 $\tau\in\{0.05\}$；可通过训练脚本启用额外网格。

\paragraph{可复现性}
我们使用种子2025，报告 $K\in\{5,10,20\}$ 的全排序指标，流行度分层阈值为 \texttt{new}:[1,3)，\texttt{few}:[3,10)，\texttt{frequent}:[10,$\infty$)。

\subsection{理解 HR--排序 权衡}

HR 和排序指标（MRR/NDCG）之间观察到的权衡乍看之下可能违反直觉——在传统排序设置中，更好的排序质量通常与更高的命中率正相关。然而，在对整个物品目录（$>$12K 物品）进行\textbf{全排序}的设置下，这种权衡既是预期的也是有意义的。

\paragraph{为什么会出现这种权衡？}
交叉网络和白化产生\emph{更尖锐的分数分布}，其中少数物品获得显著高于其他物品的分数。这种"赢家通吃"效应有利于 Top-1 准确率（MRR），但可能将相关物品推到 Top-$K$ 边界之外（损害 HR@$K$）。
相反，移除这些组件会产生\emph{更平滑的分数分布}：更多物品聚集在决策边界附近，使更多真实相关物品进入 Top-$K$（更高 HR），但代价是 Top-1 排序不够精准（更低 MRR）。

\paragraph{从业者指南}
这种权衡意味着根据部署场景的明确设计选择：
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{候选生成/召回导向系统}：如果目标是最大化 Top-$K$ 中的相关物品数量（如第一阶段检索），考虑不使用显式交叉交互的轻量级融合。
  \item \textbf{精排/精度导向系统}：如果目标是将最相关的物品放在位置1（如重排序阶段），保留交叉网络和白化以获得更强的区分能力。
  \item \textbf{平衡系统}：使用 NDCG@$K$ 作为主要指标，它通过位置加权增益自然地平衡覆盖率和排序质量。
\end{itemize}

\section{结论}
我们提出了 \model，一个结合归一化多视图文本特征、显式交叉交互和多视图对比对齐的序列推荐插件框架。
我们在亚马逊美妆和玩具游戏上的实验揭示了几个实用洞察：

\textbf{(1) 文本特征带来显著增益}：仅 \tfidf 就在美妆上提升 HR@10 +27.5\%，在玩具上提升 +14.9\%，相比仅ID基线，NDCG 增益更大（+40.9\% 和 +33.1\%）。

\textbf{(2) 交叉网络和白化对排序至关重要}：我们的消融实验表明，移除交叉模块增加 HR 但急剧降低 MRR（美妆 $-$12.7\%，玩具 $-$15.5\%）和 NDCG。白化对多视图至关重要（无白化时 MRR $-$17.2\%），但对单视图不重要。

\textbf{(3) 多视图缩放因数据集而异}：在美妆上，14B 取得最佳结果（相比仅ID HR@10 +32.6\%），但 32B 未能进一步提升。在玩具上，32B 持续优于较小模型（HR@10 +17.6\%）。

\textbf{(4) 存在 HR-排序权衡}：改善排序质量的组件（交叉、白化）可能略微降低 HR，揭示了一个基本的设计权衡，从业者应根据其主要目标进行考虑。
