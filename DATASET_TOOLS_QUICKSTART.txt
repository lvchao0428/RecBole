三、输出文件说明
================================================================================

使用 run_complete_analysis.sh 会生成以下文件:

1. analysis_results.json
   - 完整的统计数据（JSON格式）
   - 包含所有指标的详细数值
   - 可用于后续分析或导入其他工具

2. analysis_table.md  
   - Markdown格式的对比表格
   - 适合在GitHub、文档中展示
   - 可直接复制到论文或报告

3. analysis_table.tex
   - LaTeX格式的表格
   - 适合学术论文使用
   - 可直接插入LaTeX文档

4. analysis_basic_stats.png (需要matplotlib)
   - 基础统计指标对比图
   - 包含6个子图：用户数、物品数、交互数等

5. analysis_distribution.png (需要matplotlib)
   - 交互分布对比图
   - 用户和物品的百分位数分布

6. analysis_gini.png (需要matplotlib)
   - Gini系数对比图
   - 显示交互分布的不均匀程度

7. analysis_report.txt
   - 完整的分析报告
   - 包含所有生成文件的列表

示例输出:

指标                       MovieLens-1M             Amazon Beauty            
----------------------------------------------------------------------------------------------------
用户数                      6,040                    22,363                   
物品数                      3,416                    12,101                   
交互总数                     999,611                  198,502

差异分析:
• 用户数: Amazon Beauty 是 MovieLens-1M 的 3.70 倍
• 物品数: Amazon Beauty 是 MovieLens-1M 的 3.54 倍
• 交互总数: MovieLens-1M 是 Amazon Beauty 的 5.03 倍
• 用户交互密度: MovieLens-1M 用户平均交互是 Amazon Beauty 的 18.63 倍

解读:
  ✓ MovieLens数据更密集（稀疏度低）
  ✓ Amazon Beauty用户交互少（平均8.88次 vs 165.48次）
  ✓ MovieLens适合测试协同过滤
  ✓ Amazon Beauty需要内容特征辅助

================================================================================
六、关键指标含义速查
================================================================================

稀疏度 (Sparsity):
  • 公式: (1 - 实际交互数 / 可能交互数) × 100%
  • 越高越稀疏
  • MovieLens: ~95% (较好)
  • Amazon: ~99.9% (极度稀疏)

密度 (Density):
  • 公式: (实际交互数 / 可能交互数) × 100%
  • 密度 = 100% - 稀疏度
  • 越高数据质量越好

Gini系数:
  • 范围: 0~1
  • 0 = 完全均匀分布
  • 1 = 极度不均（少数占据大部分）
  • 高值表示长尾效应严重

用户平均交互:
  • 每个用户平均有多少次交互
  • 高值表示用户活跃度高
  • MovieLens: ~165次
  • Amazon Beauty: ~9次

================================================================================
七、常见问题解决
================================================================================

Q1: 执行脚本提示 "Permission denied"?
A1: chmod +x *.sh

Q2: matplotlib相关警告?
A2: pip install matplotlib (可选，用于生成图表)

Q3: 如何只看稀疏度对比?
A3: python3 dataset_statistics.py --example --metrics sparsity

Q4: 服务器上数据集路径怎么写?
A4: 完整路径，例如: /home/user/datasets/ml-1m

Q5: 能分析多少个数据集?
A5: 无限制，但建议2-5个数据集对比效果最好

八、进阶技巧
================================================================================

技巧1: 批量分析所有数据集
  for dataset in dataset/*-example; do
      name=$(basename $dataset)
      python3 dataset_statistics.py --datasets "$dataset:${name%-example}:$name"
  done

技巧2: 在Python中使用
  from dataset_statistics import DatasetAnalyzer
  
  analyzer = DatasetAnalyzer('dataset/ml-1m-example', 'ml-1m')
  stats = analyzer.analyze()
  print(f"稀疏度: {stats['sparsity']:.2f}%")

技巧3: 导出CSV格式
  python3 -c "
  import json, csv
  data = json.load(open('analysis_results.json'))
  # 转换为CSV...
  "

技巧4: 自动化对比报告
  ./run_complete_analysis.sh full /data/datasets
  cat analysis_table.md | mail -s '数据集分析报告' your@email.com
